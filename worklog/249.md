# 249: Jepsen nightly, #245 follow-ups

2026-11-06, PR #249 (fixes #245).

- A night that ends early archives the runs that finished, so an issue names an archive that survives.
- The first `host-failure` reason stands; a later end does not overwrite it.
- A reporter exit 2 is logged as an environment fault (rate limit, GitHub unreachable), not as a second report.
- A run whose workload cannot be read no longer counts as `bank` in the missing-workload check.
- `--expect-workloads` is in the reporter's usage docstring and the README usage line.
- Review fixes: the archive's 30 s limit applies only on the early-exit path (the stop budget is now 110 s of `TimeoutStopSec=120`, guarded by the unit test); `make_archive` does nothing with no archive path; the exit-2 message names a usage error.

No design choice beyond the issue, so no decision file.
