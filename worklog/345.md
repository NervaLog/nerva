# 345 — Mac signing in CI, slice A3: wired into the release

2026-11-11

- `release.yml` gains `mac` (`needs: [version, release]`, `if: github.ref == 'refs/heads/main'`, calls
  `mac-sign.yml`) and `mac-verify` (`needs: [version, mac]`, calls `mac-verify.yml` on the draft).

  triggers; headers now say the zip is signed in CI with the owner's Mac as fallback, and the brew
  error names the `homebrew-formula` artifact.
