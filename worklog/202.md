# 202

2026-11-06, PR #202 (replacing #201, whose history carried a build cache). `nerva start --trace=<file>` removes the trace file it created when startup
fails before any span is worth keeping (`Tracer.init`, for example a bad `--statsd` with NRV-E0010,
or `Storage.init`), so the operator's second start with the fixed flag is no longer refused with
NRV-E0004 (#197). A file that existed before is still refused and never touched. Test in
`tests/errors/commands.py`. No design choice beyond the issue's own first option, so no decision file.

Review fixes (Opus review of #202): the removal is now a hook in `src/nerva/diagnostic.zig`
(`cleanup_register`, run by every exit through `fail`, `fail_file`, `unexpected` and `fail_error`,
cleared once the replica has opened), so NRV-E0007, E0710, E0901, `replica.open` errors and
out-of-memory also remove the file. It skips a path that no longer names the file this run created
(inode check). A failed removal is warning NRV-W0011, in words. Tests in `tests/errors/commands.py`.
