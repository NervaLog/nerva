# 147: Production milestones, rules adopted from Zigbox, error codes

2026-11-04, [NervaLog/nerva#147](https://github.com/NervaLog/nerva/pull/147).

- `docs/PRODUCTION.md`: milestones R1 to R7 from a production review for Botpike, in Zigbox's
  style; R1 to R5 gate the first client's money (P147d). README gains a Production table, and
  the site a Production section; the site's repository link moves to `NervaLog/nerva`.
- CLAUDE.md adopts the rules from Zigbox's AGENTS.md that apply (P147): milestones and demos,
  `REVIEW.md`, agent context discipline, status kept in step, disk and environment facts. The
  release gate grows to sim-clean, Jepsen-clean, two independent reviewers and a retro (P147b).
- `docs/ERRORS.md`: about 90 registered error codes mapped from today's texts, with blame and
  fixes; codes reach the wire in R4 and the commands in R5 (P147c).
- No code changed.
- Every workflow moves to GitHub's hosted runners, since the repository is public (P147e). A
  change to `site/` alone runs only the Pages deploy (P147f).
- R4 becomes "beside its client": a gateway per client process on loopback (P147g). A new R8 adds
  a native JVM client, with no gateway in its path.
- **The simulation fleet (R2, P147h, P147i):** `ops/sim-fleet/`, modelled on Zigcube's.
  - `run.sh` follows `main` and builds the VOPR for both state machines, its full-log variants and
    the fuzzers once per tip in ReleaseSafe. It runs fresh seeds on every core but one, in
    15-minute rounds.
  - `sim_fleet.py` is the reporter, Python standard library only. It files one `sim-fleet` issue
    per fingerprint of target, exit class and normalised signature, comments per new commit
    (capped per day), and posts daily totals to a tracker issue.
  - Also: a hardened systemd unit, `setup.sh`, and a README for the owner.
  - **Checked:** 32 unit tests, a dry run of `run.sh` that built all five binaries and ran a
    20-second round, and synthetic failures of each exit class.
  - **Not checked:** no host is provisioned and no real issue was filed.
