# 115 — Release review fixes: README Limits, the 413 reason phrase, P115 (#110, #111)

2026-10-07

- From the 0.5.0 release review (P105). README "Limits" now matches the gateways: only `nerva api`
  takes a body (4 MiB; `nerva view` answers `GET` only and refuses any body with `400`); more than
  256 keys in a `get` answers `400`, the chunk budget `413`; a method a gateway never takes answers
  `405` before the key is checked (#110).
- `http_connection.reason_phrase` names 413 (`Content Too Large`, RFC 9110), so no status line goes
  bare; a unit test covers every status the gateways answer (#110).
- P115 amends P102: a 0.0.4 replica dialed by a 0.0.5 one exits with `unknown_vsr_command`
  (status 7) on `peer_hello`; it does not close the connection. README says so (#111, like #95).
