# 161: R5 slice 7, demo-r5

2026-11-05, [NervaLog/nerva#161](https://github.com/NervaLog/nerva/pull/161).

- `tests/demo/r5.py` and `zig build demo-r5` run the brief's 12 steps:
  - a replica lost and recovered while writes go on, until it leads a view;
  - a backup, then a restore drill into a second cluster;
  - a wipe and a restore of the first cluster;
  - a refused restore from a damaged backup.
- CI runs it as the `demo_r5` job.
- The README has "Replacing a lost replica" rewritten around `nerva recover`, and a new "Backups" section. `docs/demos/r5.md` holds the local run.
