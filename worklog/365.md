# 365: the domain, and the apt and dnf repositories: spec

2026-11-12, PR #365. The owner moved the apt and dnf repositories from v0.7.2 to v0.7.1. This PR
adds the spec, `docs/releases/packages.md`, with the setup steps and the slices, and P365, which
amends P360 point 10 and P148.

- **Architecture.** The site moves to Cloudflare Pages on `<domain>`, and GitHub Pages sends
  visitors there. The repositories are an R2 bucket served by a Pages Function in the site
  repository.
- **Jobs.** Three jobs in `release-finish.yml`, in their own environment, `package-repos`.
- **Channels.** Prereleases go to an `rc` channel, and releases go to `stable`.
- **Codes.** It reserves NRV-E1139 to E1147. Slice 0 registers them in `docs/ERRORS.md`.

Docs only. Nothing was built or run.
