# #474 — v0.7.1 retro

2026-11-15. NervaLog/nerva#474.

`docs/retros/v0.7.1.md` covers v0.7.1, published 2026-11-15 05:21 UTC, 11 h 40 min after its
`VERSION` commit. Its six wrong assumptions:
1. The finish chain had been rehearsed. The `rc.2` rehearsal never ran: nine runs and five fixes.
2. A job that passes before `publish` means the jobs after it are set up. `PACKAGES_BASE_URL` was
   set only on the environment, and the Worker was not serving.
3. The runner's Homebrew behaves like the one `mac-verify` was written for. Current Homebrew
   refused the untrusted tap (#466, fixed by #467).
4. The held pull requests can merge in any order. #412 got a MUST from the merge order.
5. A worktree's own Zig cache stays out of commits. #469 committed 77 MB of it.
6. A red check that passes on a re-run is noise. #403's gpg flake is now filed as #472.

The retro also gives every release run with its cause, read from the job logs.

P474 sets five rules, and `CLAUDE.md` follows them:
- the release PR quotes the rehearsal run, or the owner's waiver;
- held pull requests merge one at a time;
- `ZIG_GLOBAL_CACHE_DIR` stays outside the worktree;
- a watcher waits for check runs to exist;
- a review brief takes its SHA from GitHub.

Filed: #472 (the flaky gpg keygen), #473 (check the repository variables and the live site before
`publish`). `docs/ROADMAP.md` now shows v0.7.1 as released. README's Production table was already
current: no milestone's status changed.
