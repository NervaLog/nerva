# 113 — perf/nightly exports NERVA_CLUSTER_KEY

2026-10-07

- `perf/nightly/run.sh`: export a throwaway per-run `NERVA_CLUSTER_KEY` (if unset) before any
  replica is started. From protocol release 0.0.5 (P102) `nerva start` requires the key in
  production mode, so without it every perf replica exited at startup on 0.5.0 and all `load`
  workloads failed. The perf cluster is single-host loopback and the key is never shared, so a
  random per-run key is correct; production mode is kept (no `--development`). Compatible with
  both baseline (0.4.0 ignores the key) and candidate (0.5.0 needs it). Fixes #108.
