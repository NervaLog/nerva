# #478 — a bundled replica polls its real binary path

2026-11-18. NervaLog/nerva#478, fixing #477.

`bundle_open` freed the path that `MultiversionOS` keeps. A bundled `nerva start` then got
`FileNotFound` on every poll, one error a second. It never saw a replaced binary, so it never
offered the release that binary bundles. Its re-execution at open also named a garbage path.

`start` now owns the path and frees it after `MultiversionOS.deinit` (P478), as upstream's
`Command` does.

`test:release` builds `nerva_next_other`: the next release again, bundling the other test release
(0.0.200) in place of `nerva`. `bundle.py` then:
1. formats a data file with `nerva_next` and starts a copy of `nerva_next` on it;
2. checks that three polls pass without an error;
3. renames `nerva_next_other` over the running binary;
4. waits for `releases_bundled new: { 0.0.200, 0.0.206 }`.

Before the fix, the check fails at step 2 with `error.FileNotFound`.
