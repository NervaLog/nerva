# 170: R4 slice 1, the Receiver

2026-11-05, [NervaLog/nerva#170](https://github.com/NervaLog/nerva/pull/170). Fixes #112.

- The gateway's Receiver opens its own socket without `SO_REUSEPORT`.
- Every connection it closes reads a status line first. A refused socket lingers briefly so the client gets the reply.
- Only silent connections are displaced (`503 busy`, NRV-E0602). A late request gets `408` (NRV-E0116).
- Refusals carry `code` and `applied` (P170 to P170c).
