# 390 — packaging: restart-policy test race, QUICKSTART exit 1

2026-11-13. PR #390, fixes #375 and #385.

- #375: `test_restart_policy` counted "Started" lines; the failing run had the refusal in its log
  and was one short, so systemd had not logged one start. It now asserts `NRestarts == 20` (systemd's
  own counter), counts "Starting" and "Main process exited" loosely (>= 19) because a line can go
  missing from `journalctl -u`, and prints the counts and the whole journal when a check fails.
- #385: the unit is right (exit 1 restarts); QUICKSTART now lists `2` to `8` and `70` as not
  restarted (P390).
