# 344 — Mac signing in CI, slice A2: mac-sign.yml and the draft check

2026-11-11

- `.github/workflows/mac-sign.yml` signs, notarizes and uploads the universal macOS zip to a draft
  release under the `apple-signing` environment (inert until it exists). `release_check.sh mac-draft`
  refuses a non-draft or missing release (NRV-E1119), a target whose `VERSION` is not the tag
  (NRV-E1120) a release off `main` (NRV-E1124), a tag that is not v<VERSION> (NRV-E1123) and a target or VERSION GitHub cannot read (NRV-E1122), before the secrets are unlocked and again before
  the upload. Tested with a stand-in `gh` in `test_release_check.py`. Wiring into `release.yml` is A3;
  the keychain script and the codes' registration are A1.

Review fixes: release_check.sh and mac_keychain.sh are fetched from the workflow ref, never the target; the cleanup step is skipped when the draft was refused.
