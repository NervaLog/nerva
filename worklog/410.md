2026-11-13. [#410](https://github.com/NervaLog/nerva/pull/410): the site moves from Cloudflare Pages to a Worker of static assets built by Workers Builds (P410, amending P365 and P398). The gate is now `.github/scripts/site_build.sh`, fetched by the dashboard's build command at a pinned commit and SHA-256 (P410b, NRV-E1164), which writes the only Wrangler configuration (no `main`, no binding); deploy and preview run a pinned Wrangler with `--config`. Previews and `workers.dev` stay on (P410c). The build token Cloudflare offers reaches R2, so a narrower one is specified, with its residual reach accepted by the owner on 2026-11-13 (P410d, P410e). `test_site_build.py` runs the gate on fixture trees and checks the commands' lengths; it runs in `ci.yml`'s release-scripts step. `docs/releases/packages.md` and `docs/ERRORS.md` updated.
