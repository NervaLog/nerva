# PR 330

2026-11-11. Packages: the rockylinux:9 upgrade step sees NRV-W1101, fixes #329.

- The rpm flow in `tests/packaging/packages.py` ran the upgrade as `dnf install -y -q`; dnf's `-q`
  hides a successful scriptlet's stderr, so the grep for the NRV-W1101 warning failed and main's
  Packages run went red with #326. The upgrade now runs without `-q`, as an operator would, and
  prints dnf's output when the install fails or the warning is missing.
- The assertions that the upgrade succeeds, warns, and keeps the data and the enabled replica are
  unchanged. No product change.
