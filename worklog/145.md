# PR 145

Date: 2026-10-26

A project site on GitHub Pages (P145). `site/build.py` renders a listed set of pages (a home
page, the tutorial, the 1.0 goals and milestones, the README and the changelog) with GitHub's
Markdown API, keeps links between them on the site and points every other repository link at
github.com. The home page lists the tutorial's parts and a milestone table that the build checks
against `docs/GOALS-1.0.md`. `.github/workflows/pages.yml` deploys it from `main`; `ci.yml` runs
`site/test_build.py`.
