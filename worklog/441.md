# 441: quickstart loop for #305

2026-11-14. PR #441. Added `scripts/quickstart_loop.sh`, which runs the one-machine quickstart in a loop
and reports time to the gateway's `listening` line. 30 idle runs (max 1.17 s) and 30 loaded runs
(max 1.23 s) on main 11b218f: the ~100 s hang of #305 did not reproduce.

Review fixes: the script now traps EXIT/INT/TERM (kills every child, bounded wait then SIGKILL, removes data),
checks the ports are free and each replica is alive and listening, stops at once with the error line if the
gateway exits (exit 3), reports the format error, times with perl (ms on macOS), drops bc/realpath, and refuses
to run if its commands are no longer on docs/QUICKSTART.md.

Second review round: the SIGTERM wait now really polls up to 10 s against a deadline (a child exiting after 3 s is
not killed or reported); cleanup ignores INT/TERM so a double Ctrl-C still removes the data; not-ready healthz makes
the exit status 1 and names the run; the binary (bare names via PATH), runs and slow_s are validated (exit 2); the
drift guard reports a missing page in one line and guards the X-Nerva-Key header; each invocation works in its own
`loop.XXXXXX/` under the workdir, so it never removes or reuses anything it did not create.
