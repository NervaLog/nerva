# 114 — The nightly perf run gives its replicas a cluster key (#108)

2026-10-07

- Since P102, `nerva start` needs `NERVA_CLUSTER_KEY`; `perf/nightly/run.sh` set none, so every
  replica exited and every `load` workload recorded zero operations, which `compare.py` skips
  silently. `run.sh` now exports a random 32-byte key per run (kept if one is given, never
  printed), and a replica that exits at start records an `error` per workload.
- Verified by running `run.sh` locally against release builds of main without `--development`:
  zero operations before, real throughput after; a too-short key records the errors.
