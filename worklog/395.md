# 395: `format` blames the right layer (#372)

2026-11-13. PR #395, held until the v0.7.1 tag (P374, P389).

`nerva format` now reports a data file it cannot use (missing directory, a parent that is a file, no write permission) as NRV-E0810 through `fail_file`, as `start`, `export` and `import` do. Before: NRV-E0007 "cannot listen" for permission denied, and `bug[NRV-B0004]` (exit 70) for a missing directory. NRV-E0810's registered text is widened; TROUBLESHOOTING gets a row; `tests/errors/commands.py` covers the three cases. No new code, no format change.
