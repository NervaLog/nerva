# PR #427 (fixes #198), 2026-11-14

`nerva start --statsd` with an address the host cannot send to no longer stops the replica. The
owner approved option (a): the vendored `StatsD.init_udp` (`src/trace/statsd.zig`) no longer
connects its UDP socket; `emit_buffer` sends each packet with `sendto`, as `nerva api`'s emitter
does. The first failed send warns once, NRV-W0733; later ones are only counted. NRV-E0010 stays for
a family the host has no socket for. Broadcast now warns on `start` (it still refuses on `api`).
Added `src/nerva/statsd_unroutable.zig` (unroutable keeps running and warns once; loopback
collector receives), UPSTREAM.md entry, `docs/decisions/P427-*.md`, ERRORS.md W0733, README and
`tests/errors` updates.
