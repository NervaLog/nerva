# PR 291: `zig build mac-release`, `nerva version`'s version line, the formula

2026-11-10. v0.7.1 slice 3 (brief, P284, P284b).

- `-Dversion` (default `VERSION`) and a last `version <VERSION>` line in `nerva version`; the
  first lines and the format digest are unchanged.
- `zig build mac-release` (`src/nerva/mac_release.zig`): preflight before the build, then lipo,
  sign, verify, run, zip, CDHash check, checksum, optional notarization, formula. Pure parts are
  unit tested on Linux; the Mac calls run only in slice 2's job and on the owner's Mac. Run it as
  `zig build -Drelease mac-release`: without `-Drelease` the step refuses, since the thin
  binaries would carry the simulator's extra verification (`config_verify`).
- Review fixes: `-Dversion` is validated at build time; the zip is built with `--norsrc` and its
  listing checked; each architecture slice's signature is verified; `--notarize` reaches
  preflight; tools are called as `/usr/bin/...`.
- `packaging/homebrew/nerva.rb` is the formula template. UPSTREAM.md records both vendored
  patches. Decision P291 settles the defaults.
