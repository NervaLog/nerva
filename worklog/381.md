# 381: installer failures get a code

2026-11-12. Pull request 381, fixes #378.

`install.sh` and `package-setup.sh` stopped with the tool's own message when `useradd` or `install` failed.
Each call now prints one NRV-E1163 block after that message and exits 1 (registered in docs/ERRORS.md).
Tests stub the tools: `test_setup_failures` in tests/packaging/install.py and `check_setup_modes` in
tests/packaging/packages.py.
