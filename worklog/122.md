# 122 — Perf nightly: hold the baseline while a regression is open; close only filed issues

2026-10-08, https://github.com/Botpike/nerva-ledger/pull/122

- Fixes two bugs in #121 (P122 amends P121). A warn night no longer advances the baseline
  while a fingerprinted `perf-regression` issue is open (`file_issue.py` writes
  `advance_baseline` to the issue step's output, and the workflow runs that step before
  recording), so fail, warn, fail is one issue and the baseline does not absorb the regression.
  An open issue is also matched by metric, so P121-format fingerprints against an older baseline
  still match. A passing night closes only issues with a fingerprint marker.
- Tests (`perf/nightly/test_file_issue.py`): fail, warn, fail keeps one issue and the
  baseline; `advance_baseline`; the workflow's baseline condition run in bash; old-format
  fingerprints (open by metric, closed by exact match); a hand-filed issue survives a pass;
  `--github-output`.
- README: the nightly paragraph.
