# 354 — The keys-off build runs its own release

2026-11-12, PR #354, closes #222.

`-Dtest-commit-keys=off` is now built as this release with its patch plus 201 (`build.zig`;
`0.0.207` for `0.0.6`), so replicas of it and of a release build ignore each other (N61) and
refuse each other's data files (NRV-E0701) instead of diverging on a resent key. A cluster that
evicts a client for its release (`client_release_too_high` or `_too_low`) is now NRV-E0609 or
NRV-E0610 in every command and in a gateway's log, not `bug[NRV-B0004]` (#356). NRV-E0701's fix
names the keys-off exception. No format changes. `tests/errors/commands.py` covers it; decision
P354.
