# 445: sim-fleet retries a broken commit

2026-11-14. PR #445, refs #289.

`run.sh` retries a commit in `state/broken` after a wait, at most three times, counted in
`state/broken-tries` (P445). New tests for the bound, the wait, a missing file and a new head,
and for a `git status` that fails (#436's SHOULD); the `restore_built` log line names the
condition that held (#436's NIT). README documents the retry, clearing it by hand, and the state
`version` rule. The live fleet picks this up only when its pin moves.

Review fixes, in the order they landed: `SIM_FLEET_BROKEN_RETRIES` and `_RETRY_SECONDS` are
validated as whole numbers at startup; each retry keeps `build.log.<attempt>`; ERRORS.md E0731
and `follow_main`'s comment are updated. A malformed setting is refused with NRV-E0740
(registered, tested), values with a leading zero are read as decimal (`08`, `07200`), a six-digit
limit has a test, and a new head removes the earlier head's `build.log.<n>`.

Final rule for the attempt: it is recorded after the checkout succeeds and before the retry builds.
A failed checkout costs no attempt (NRV-E0731, tested); a build killed midway counts (a test kills
the loop six times).
