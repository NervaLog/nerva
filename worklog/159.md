# 159: R5 slice 5, the VOPR from an imported start

2026-11-05, [NervaLog/nerva#159](https://github.com/NervaLog/nerva/pull/159).

- `src/nerva/vopr_start.zig` builds a deterministic export from the seed. `import.zig` reads an export from memory as well as from a path. The testing cluster imports the export into every replica, and the state checker starts at its checkpoint (P159).
- About half of the `nerva` lane's seeds start imported. At the default draw, seeds 1070 (checkpoint 39) and 1103 (checkpoint 59) start imported, reformat a replica, and pass. Seeds 12 to 400 pass.
