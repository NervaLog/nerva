# PR 383 (2026-11-13)

Fixes #373. `replica.env.example` and `api.env.example` ship `NERVA_CLUSTER_KEY=` and `NERVA_KEY=`
empty, so an unedited copy is refused by the binary's existing checks (NRV-E0901, NRV-E0008)
instead of starting on a published key. `docs/QUICKSTART.md` describes the refusal;
`tests/packaging/install.py` gains `test_env_examples`, which runs each shipped example against the
real binary. No change under `src/`, `build.zig`, `build.zig.zon` or `zig/` (code freeze).
