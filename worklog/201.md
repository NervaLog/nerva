# 201

2026-11-06, PR #201. `nerva start --trace=<file>` removes the trace file it created when startup
fails before any span is worth keeping (`Tracer.init`, for example a bad `--statsd` with NRV-E0010,
or `Storage.init`), so the operator's second start with the fixed flag is no longer refused with
NRV-E0004 (#197). A file that existed before is still refused and never touched. Test in
`tests/errors/commands.py`. No design choice beyond the issue's own first option, so no decision file.
