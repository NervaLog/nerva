# 2026-11-18, #490

The packer now refuses a past release that does not state `multiversion offers_from_binary` under
`version --verbose` (NRV-E0728, P490, fixes #484). v0.7.1 reports the same format digest as main but
runs as one release and would leave a cluster waiting for replicas to offer the new release.
`bundle.py` starts a packed binary on the past release's data file and sees the one-replica cluster
upgrade, and refuses a stub and a real build (`nerva_past_single`) without the line.
