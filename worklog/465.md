2026-11-14. NervaLog/nerva#465, fixing #464.

`site_release.py` was looked up relative to a scratch clone, because `$0` is relative and
`site_clone` changes directory first. The script now resolves its own directory once; a new test runs
it by the relative path the workflow uses.

passes as the relative `formula/nerva.rb`; `tap` failed after the draft was published and `tap-check`
checked nothing (`tap_diff` hid diff's exit 2). `tap_run` now makes the path absolute first and
refuses a missing file, and `tap_diff` refuses an unreadable file or a diff failure (NRV-E1135).
New tests run both steps by the workflow's relative paths.
