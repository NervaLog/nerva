# PR 382 (2026-11-12)

Fixes #370. Every sim-fleet round is now settled by a record in the state file
(`last_round`, saved in the same atomic write as the round's count), never by an exit code:
`ingest` counts or refuses the round before it needs the token or GitHub; `run.sh` checks the
record after `ingest` and falls back to `sim_fleet.py refuse`; a round nothing could record stays
in place and the loop stops for systemd to retry; a round left by a restart is settled from its
results. A refused round makes its commit not clean for `soak`. Removed the exit-code table, the
exit-70 wrapper and the `unrecorded-` markers. Tests in `test_sim_fleet.py` (run.sh end to end
with a stub interpreter), each fix checked by mutation; P382.
