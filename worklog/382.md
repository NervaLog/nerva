# PR 382 (2026-11-12)

Fixes #370. A fleet round that `ingest` refuses (more than 4096 failing seeds, a malformed
`results` line) or that the reporter never finished is now counted against its commit as
`refused`, and `soak` reads that commit as not clean. Added `sim_fleet.py refuse` (run by
`run.sh` for a lost round), exit 70 for a reporter bug, tests in `test_sim_fleet.py`, and P382.
