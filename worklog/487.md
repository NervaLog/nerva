# #487 — release scripts capture output before matching

2026-11-18. NervaLog/nerva#487, fixing #483.

`release_check.sh binary` piped `nerva version` into `grep -q '+keys-off'` under `pipefail`. grep
exited at its match, the writer died of SIGPIPE, and the pipeline failed: the match counted as none.
The same pattern was in `package_repos.sh`, `repo_install_check.sh` and `repos_alarm.sh`. Each now
captures the output, checks the exit status and matches the text. Acceptance and codes are unchanged.
A test with 1 MB after the `+keys-off` line fails on the old script every time.
