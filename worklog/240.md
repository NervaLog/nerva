# 2026-11-06, PR #240

Nightly NITs from #235's reviews (`ops/jepsen/`, refs #236, #241): the timer is enabled only with
a token; the reporter reads the history once per run and frees it after the run's last finding; a
crashed canary is reported as a crash with the canary's own fingerprint; the lock is taken once;
the README host table matches the brief; `nightly.sh --check-token` runs before the unit stops the
fleet; the crash is told apart from a blind canary. Tests in `test_jepsen_report.py`.

Three Opus reviews found MUSTs in the stage 1 / stage 2 self-update, each from running the tip's
tooling. P240 removes it: `setup.sh` installs `nightly.sh`, `jepsen_report.py` and the unit files
(`/opt/jepsen/bin`), the night fetches only the code under test, and a runner change reaches the
host when `setup.sh` runs again. A TERM/INT trap reports an interrupted night as the host's `error`
(exit 143) with the tracker's line. The stage machinery and the `unparsable` and `died` findings
are gone.
