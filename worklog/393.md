# PR 393 (2026-11-13)

Wrote the brief for R8, the native client (`docs/briefs/r8.md`), from `main` at `c886c9f`. The
library sends the cluster's existing extern structs, so no `Operation` value and no format
change. It runs its own IO thread and batches waiting calls of one operation into one request (at
most 1,024 batches; `views_busy` sent again once). A C ABI sits over it, with a JVM binding through
JNI. The brief has eight slices, the `demo-r8` demo, the 12xx error codes, and eight owner
questions with recommendations (JNI or the foreign-function API, the JDK, vendoring `jni.zig`,
the jar as an asset, which operations are offered, the demo cut, the #353 dependency, the order).
R8 is delivered only after #353. The R8 row in README and PRODUCTION reads "Brief written"; the
site was not updated (out of this session's access).
