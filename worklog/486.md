2026-11-18

- `StatsD.emit` returned packets built minus `send_dropped_count`, so sends refused for a route or
  permission error stayed in `metrics_statsd_packets`. It now counts successful sends
  (`send_sent_count`) and returns the growth. Owner-requested patch to the vendored
  `src/trace/statsd.zig`; its UPSTREAM.md row is updated.
- Tests: `src/nerva/statsd_unroutable.zig` asserts the published gauge is 0 for the unroutable
  destination and 1 for a reachable one and after recovery. On the old code the unroutable test
  fails with `expected 0, found 1`.
- Review: `emit` now asserts that sent, dropped (`send_dropped_count`) and failed
  (`send_callback_error_count`) packets sum to the packets built. The tests also pin the 0 gauge
  in the window with the failures, and an emit of several failing packets.
