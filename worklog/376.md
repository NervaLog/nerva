# 376

2026-11-12, NervaLog/nerva#376. The package-repository spec (`docs/releases/packages.md`)
amended to the Zigbox team's review, with the owner's decisions of 2026-11-12. Spec and
decisions only, no code. P376: an offline certify-only primary with a yearly CI signing subkey,
adopted only if a new slice K passes on every rpm and apt verifier (single-key fallback written
out); every signature pinned to the primary and the subkey's role; verify before upload
(NRV-E1161); every written object fetched back byte for byte (NRV-E1145); an `alarm` job filing
one `package-repos` issue (NRV-W1103), `repos-fresh` at 10 days; the key by WKD on `nerva.pro`
as a second channel (NRV-E1162); `Date` from the signing run. P376c: the plan
for `macos-15-intel`'s retirement (slice M, Rosetta). New slice order: 2 with K, 0b, 2b, setup
step 4, 3, 4, 5, rehearsal.

2026-11-12, review fixes. Verify an rpm in step 4, before its hash is recorded or it is put, so no
bad object reaches a locked prefix; a bad one already there is marked `excluded` and left out of
the indexes. The alarm no longer fires on `cancelled`, assigns the issue to the owner and posts
at most once a day per (workflow, job, code). The fallback says plainly that the single key is in
GitHub, as P365 has it. The dnf adoption criterion is `dnf upgrade nerva` with no other command,
on rpm 4.16, 4.18 and 6. Both WKD checks use the key at the commit `RELEASES` names. WKD needs a
`404.html` and `_headers` and is adopted only if the rehearsal passes. #376 merges after #368.

2026-11-12, second review fixes. `excluded` is set only for an rpm signed by a subkey listed
`revoked` in `packaging/keys/`, at most 16 a run, and a later run returns it to `published`; any
other rpm failure in step 5b stops the run with nothing written (NRV-E1161). The alarm also fires
on a cancelled write job (`repos-ready`, `repos`, the refresh), and a daily
`package-repos-watch.yml` catches a refresh that never starts. The leftover "cannot be
documented" trigger is gone. The WKD reference is the key file at Nerva's newest `v*` tag,
never named by the site pull request; the old "same day" rule is removed. The ceremony wipes
`$GNUPGHOME`, `$CIHOME` and `$CICHECK` before the network comes back.

2026-11-12, third review fixes (scope cut). No run excludes an rpm on its own: any rpm that fails
step 5b stops the run with NRV-E1161, and the owner excludes or restores one key's rpms with a
`package-repos-refresh.yml` dispatch (`rpm_key`, slice 2b); the bound of 16 and the automatic
return are gone, and the Recovery table says a lasting fault waits for a person, bounded by the
alarm and the 10-day margin. P376b is withdrawn; slice G proposes its own decision after v0.7.1.
The WKD reference is the key file at the newest published `v*` tag, prereleases included, and
`site_check` no longer reads `RELEASES`. `cancelled` alarms only for `repos-ready` and `repos` in
`release-finish.yml`. The revocation certificate goes on the two offline drives.
