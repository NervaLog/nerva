## Steps, in order (CLAUDE.md)

1. The CHANGELOG section `## v0.7.1 — <date>` has no **TO FILL** left, and is the release notes.
2. This PR's commit changes `VERSION` and adds `worklog/<number>.md`; it does not touch `src/`,
   `build.zig`, `build.zig.zon`, `zig/`, `.gitmodules`, a `.gitattributes` or `release/candidate`.
3. Merging starts `release.yml`: it checks the notes, the tag and the candidate, calls `ci.yml`,
   builds the four targets, the packages, `SHA256SUMS` and the SBOM, and makes the draft.
4. `release-finish.yml` starts: the `apple-signing` job signs the Mac zip and notarizes it.
5. **The owner approves the `apple-signing` environment once.** No session approves it (P360).
   Everything after runs unattended: `mac-verify` on the draft, publishing the draft, the
   Homebrew formula to the tap, and the site's pull request.
6. If a run stops, the owner starts `release-finish.yml` by hand from `main` with the tag.
7. Within a day: `docs/retros/v0.7.1.md`, and README's status and the site's `RELEASES`.
