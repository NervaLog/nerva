# R5 demo: recover

**Status: not run.** R5's brief is [docs/briefs/r5.md](../briefs/r5.md). R5 is delivered only
when this demo is green in CI, with the run linked here.

- **The demo:** `zig build demo-r5`, which runs `tests/demo/r5.py` against a ReleaseSafe
  `nerva`, and the `demo_r5` job in `.github/workflows/ci.yml`. Neither exists yet (slice 7).
- **What it shows:** a replica whose data file is deleted is formatted again with
  `nerva recover` and catches up while writes continue; it then leads a view, and every view
  hash, the ledger's total and every acknowledged commit key agree. `nerva backup`, a restore
  drill beside the running cluster, a wipe and `nerva restore` give the same hashes. The brief's
  table, "The demo", lists every step and its expected outcome.

This document grows slice by slice: what each slice ran, the cuts (with the reason), and the
recorded output of the green run.

## Slice 4: recover on imported clusters

Run on 2026-11-05 in the cloud container, ReleaseSafe (not CI):

- `tests/release/recover.py` (in `test:release`): a formatted cluster commits and is exported,
  three replicas are imported from the export, a writer runs past a checkpoint; a replica
  recovered with `--origin=none` starts, exits 8 with NRV-E0711 naming the export, and its
  peers log that they ignore it and commit on; then each replica in turn (the primary once) is
  lost and recovered with the export's SHA-256, and with another backup stopped the commits need
  it; last, the backup that would lead the next view stops and the primary is killed with
  SIGKILL, so the recovered replica is in the view-change quorum; every acknowledged key answers
  `replayed`. About 80 to 125 s.
- The VOPR's end-of-run summary prints `reformats=<n> origin=none|non-zero`. Only about one seed
  in seventy has both a reformat and a non-zero origin (reformats happen on swarm seeds that
  crash and restart replicas); the seeds named in the PR were found by scanning.
- Cut: the VOPR still starts every cluster at op 0; reformats on an imported start are slice 5.
