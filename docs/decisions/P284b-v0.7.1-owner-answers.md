# The owner's answers on v0.7.1: alpha, standard Linux packaging tools, a frozen main commit

**Decision.** The owner answered the brief's open questions on 2026-11-10.

1. **The maturity label is alpha.** `docs/MATURITY.md` and the brief's one label line say so.
2. **Linux packages use the standard tools, `dpkg-deb` and `rpmbuild`, in `release.yml`.** Not a
   Python script and not tarball-only. **The owner approved this new tool dependency**
   (`rpmbuild`, installed with `apt-get install rpm` on the `ubuntu-24.04` release runner and
   pinned to the version recorded in slice 5; `dpkg-deb` is already on the image). The packages
   are unsigned and covered by `SHA256SUMS`. Slice 4's tarball with `install.sh` and the systemd
   units stays, and the packages reuse its unit files.
3. **The soak runs on a frozen commit on `main`**, not a `release/v0.7.1` branch. The candidate
   is one `main` commit: the fleet and Jepsen soak it, and the release is cut from it even if
   `main` has moved on, which CLAUDE.md allows. A fix found during the soak merges to `main`,
   and the soak restarts on the new commit.
4. **Slice 3's vendored patches are approved by the owner:** `build.zig` (`zig build
   mac-release`, `-Dversion`) and `src/nerva_main.zig` (the `version` line). Each must be
   minimal and recorded in `UPSTREAM.md` in the same commit as the patch.

**Defaults, not owner answers.** The supervisor's defaults for the brief's other questions, which
the owner may still override: macOS is for development and evaluation only; if the soak host is
not ready, the release waits rather than waives the gate; vulnerabilities are reported through
GitHub's private vulnerability reporting.

**Reason.** The standard tools are what Linux users and distributions expect and need no
packager of our own to maintain. A frozen `main` commit needs no branch to keep in sync, and it
soaks the exact code that ships. The vendored patches are the smallest way to build the Mac
binary and name the release.

**Cost.** `release.yml` gains a tool whose version a runner image change can move, so the job
pins and asserts it. The unsigned packages ask users to check `SHA256SUMS`. A fix during the
soak restarts the 24 hours on a new commit.
